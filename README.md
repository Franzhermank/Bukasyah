# A Little Birthday Surprise ♡

## Menambahkan lagu sendiri
1. Masukkan file musik milikmu ke folder `assets/`.
2. Ubah nama file menjadi `lagu.mp3`.
3. Buka `index.html`. Saat menekan **Buka surat** atau swipe untuk membuka surat, musik akan mulai diputar di latar belakang.
4. Jika browser memblokir autoplay, tekan tombol musik di pojok kanan atas.

File musik tidak disertakan; tambahkan sendiri `assets/lagu.mp3`.

## Menjalankan
Ekstrak ZIP, lalu buka `index.html` di Chrome atau Edge.

## Mengedit teks
Buka `index.html` dengan editor teks. Cari komentar `GANTI UCAPAN` dan `GANTI ISI SURAT`.
